# a2bubbletea

A2UI v1.0 renderer for the terminal, built on Bubble Tea.

This repository is an early scaffold. It will grow alongside the A2UI v1.0
specification.

```sh
go run ./cmd/a2bubbletea samples/text.jsonl
```

Press `q` to quit.

## Development

```sh
make lint
make test
```
