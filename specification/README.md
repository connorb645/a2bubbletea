# A2UI specification

This folder holds a git submodule of
[a2ui-project/a2ui](https://github.com/a2ui-project/a2ui), pinned at commit
`b817d0296010075ce230fdd720f00e32cd07b775` (23 October 2026).

Fetch it with:

```sh
git submodule update --init specification/a2ui
```

Useful paths inside it:

- `specification/a2ui/specification/v1_0/json/`: the v1.0 JSON schemas
- `specification/a2ui/specification/v1_0/test/cases/`: the specification tests
- `specification/a2ui/catalogs/basic/v1/`: the basic catalog and its examples

A2UI v1.0 is a release candidate; the protocol document was last updated on
8 June 2026. Upstream is Apache 2.0 licensed.
